Publish on GitHub Pages in 3 Steps

This calculator is built as a 100% self-contained single HTML file (index.html) with zero build steps required.

  1. Save File: Save this code on your computer with the exact filename index.html.
  2. Upload to GitHub: Sign in to GitHub.com, click New Repository, give it any name (e.g., sip-calculator), set it to Public, and upload your index.html file.
  3. Enable GitHub Pages: Open your repository's Settings → Pages, under Branch select main (or master) and click Save. Your live web calculator will be published worldwide within 60 seconds!
